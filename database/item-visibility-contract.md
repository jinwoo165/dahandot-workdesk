# 일정·최근 자료의 숨김과 복원

`workdesk_item_visibility`는 개인 업무보드의 표시 설정이다. 일정 원본, 참석·개인 제외 설정, 파일, 변경 기록, 본문 요약을 수정하거나 삭제하지 않는다.

- `kind='agenda'`: 원본 event ID로 다가오는 일정 목록에서만 숨긴다. 달력에는 기존 기준대로 표시된다.
- `kind='file'`: drive ID와 item ID로 최근 자료에서 숨긴다. 이름이나 수정시각이 바뀌어도 같은 파일은 숨김을 유지한다.
- RPC `set_workdesk_item_hidden(workspace,kind,drive_id,item_id,hidden)`는 소유자 권한으로 실행한다. 숨길 때 저장된 실제 원본을 조회하고 복원용 이름만 보존한다. 복원은 숨김 시각을 null로 바꾸며 과거 자료를 현재 조회 범위에 억지로 추가하지 않는다.
- 숨긴 파일을 제외한 뒤 기존 최근 7일·파일별 최신 변경 기준을 적용하여 최대 30개를 표시한다. 숨긴 항목 목록은 별도의 복원 기록이다.
- 클라이언트는 RPC 이후 workspace와 원본 ID로 해당 행을 다시 읽어 숨김 상태를 검증한다. 실시간 구독과 기존 30초 재조회가 기기 간 설정을 반영한다.
- RLS는 기존 workspace 소유자 판별을 재사용한다. 익명 읽기·실행과 클라이언트 삭제 권한은 없다. 운영 DB에 테스트 항목을 만들지 않는다.
