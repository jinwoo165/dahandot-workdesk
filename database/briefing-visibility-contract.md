# 주요내용 숨김과 복원

`briefing_dismissals`는 업무보드 표시 설정이며 업무, 원본 피드, 수집 결과를 수정하지 않는다. 같은 workspace의 소유자만 읽고 변경할 수 있고, 익명 접근과 삭제 권한은 없다.

클라이언트는 안내를 줄별로 분리하고 앞쪽 글머리표·공백·유니코드 표현만 정규화한다. 동일한 문구는 후속 피드에서도 숨기며, 날짜나 행동이 바뀐 문구는 새로운 안내로 표시한다. 의미 유사도만으로 새 요청을 숨기지 않는다.

`set_workdesk_briefing_hidden(p_workspace uuid, p_line text, p_hidden boolean)`은 호출자 권한과 기존 workspace 접근 정책으로 실행된다. 동일 문구의 중복 숨김은 한 행으로 유지하고 복원은 `hidden_at=null`로 보존한다. MD5는 텍스트 식별용이며 암호·인증 용도가 아니다. 충돌 시 본문 일치를 확인하고 다른 문구를 덮어쓰지 않는다.

화면은 RPC 이후 해당 workspace/line_key를 재조회하여 문구와 숨김 상태가 일치하는지 검증한다. 저장이나 확인이 실패하면 성공으로 알리지 않는다. 숨김 이력의 복원은 현재 주요내용에 포함된 문구만 다시 표시하며 지난 안내를 현재 안내에 추가하지 않는다. 실시간 변경과 기존 주기적 재조회가 다른 기기에도 설정을 반영한다.

운영 DB에는 테스트 업무·대화·설정을 만들지 않는다. `tests/briefing.sql`은 분리된 로컬 PostgreSQL에서만 실행한다.
